# 🐧 Linux Fundamentals

Laboratório prático desenvolvido para consolidar os fundamentos do Linux e da linha de comando (CLI).

Neste projeto, são praticados conceitos de navegação no filesystem, criação e gerenciamento de arquivos e diretórios, caminhos absolutos e relativos e utilização de comandos essenciais do Linux.

## 🎯 Objetivo

Desenvolver familiaridade com o ambiente Linux por meio da prática, entendendo não apenas quais comandos utilizar, mas também o que acontece no filesystem a cada operação.

## 🧪 Conteúdos praticados

* Navegação pelo filesystem
* Caminhos absolutos e relativos
* Criação de diretórios e arquivos
* Cópia, movimentação e remoção de arquivos
* Localização de arquivos e diretórios
* Visualização da estrutura de diretórios
* Uso da linha de comando (CLI)

## 🛠️ Comandos utilizados

`pwd` · `ls` · `cd` · `mkdir` · `touch` · `cp` · `mv` · `rm` · `find` · `tree`

## 🧩 Desafio

Criar e organizar a seguinte estrutura:

```text
lab-linux/
├── logs/
├── scripts/
├── backups/
├── config/
└── reports/
```

Durante o exercício, serão documentados os comandos utilizados, os caminhos empregados e as diferenças entre caminhos absolutos e relativos.

## 📸 Evidência

Print do terminal demonstrando a estrutura final criada e os comandos utilizados durante o laboratório.

## 📚 O que este laboratório demonstra

Este projeto demonstra conhecimentos básicos de utilização do Linux pela CLI e serve como base para os próximos laboratórios, que irão evoluir para usuários e permissões, processos, serviços, redes, Bash e troubleshooting.
